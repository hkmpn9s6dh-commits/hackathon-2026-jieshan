# 借山 · Borrowed Mountain

> 无锡寄畅园 · 五个年代 · 一种手法
> 2026 无锡「火蜜桃」·AIGC 创新大赛 · 赛道 B（AI 小游戏与互动影游）

**园子只有十五亩。山，是整个江南的。**

---

## 它是什么

一个 8 分钟的互动影游，五关，一关一个年代。每一关只给你两三个可动的东西，
你要做的事只有一件：**借**——把墙外的山、塔、水，框进园子里。

| 关 | 年代 | 借什么 |
| --- | --- | --- |
| 1 | 明·正德年间（约 1527）· 凤谷行窝 | 借山：墙要多高，树要挡在哪 |
| 2 | 1599 · 寄畅园 | 借塔：龙光塔要落在两根廊柱之间 |
| 3 | 1751 · 南巡 | 把整座园子借进一张 3:2 的画 |
| 4 | 1860 · 庚申 | 只剩一段断墙，让开塔，给水留一条 |
| 5 | 2026 · 回借 | 墙外起了高楼，把记忆里的塔放回去 |

判定用的是几何：山脊、塔框、画幅、雾带，全部是坐标算出来的。
「看起来对了」和「判过」是同一件事——判据用的那条山脊线，就是从画面里量出来的
（页面上加 `?ridge=1` 可以把这条线画出来）。

## 跑起来

```bash
npm ci
npm run dev        # http://localhost:5173
npm run build      # 出 dist/
npm run verify     # 91 条交付物断言（几何、文案出处、素材、构建产物）
npm run e2e        # 38 条浏览器断言（真拖、键盘、触屏、落印、存图、手机视口）
```

一次跑完全部：

```bash
bash verify.sh
```

`e2e` 需要一个 Chromium。默认读 `CHROME_PATH`，没设就用
`C:/Users/<you>/AppData/Local/ms-playwright/chromium-1248/chrome-win64/chrome.exe`；
换机器时把 `CHROME_PATH` 指过去即可（`npx playwright install chromium` 也行）。

## 结构

```
src/core/geo.ts     几何与判据（纯函数；渲染和验证共用同一份）
src/core/text.ts    全部文案与出处（每句引文都挂 source key）
src/core/paint.ts   绘制：纸、远山、塔、树、墙、水、印
src/core/game.ts    状态机、输入、HUD、卷末、存图
scripts/verify.mjs  交付物断言
scripts/e2e.mjs     浏览器断言
scripts/subset_fonts.py  字体子集（改字必重跑）
public/assets/      生成的水墨素材（远山、塔、树、粉墙）
```

## 素材与合规

- 画面全部自绘或自生成；**不使用任何实景照片**、不引外部 CDN、不用第三方图标库。
- 远山、塔、树、粉墙四张图由生成式模型产出（提示词见 `docs/04-PROOF.md` §5），
  塔与树转成 alpha 墨层后使用，不保留原白底。
- 字体 Noto Serif SC（SIL OFL 1.1）子集，随包提供，不依赖系统字体。
- 页面内「AI 说明」逐项写明哪一部分是生成的。
