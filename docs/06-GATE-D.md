# 06 · 闸 D（审美）

> 规则：成品与往届得奖作（≥5 件）混排、随机字母命名，至少两位没参与的模型各自排名；
> 每一位都把它排在至少 3 件得奖作之上才算过线。

## 本场的特殊性

这是**首届**赛事，没有往届得奖作可混排。按本工作区既定的替代做法（前几场用过、已写进中枢）：

- 用**同题多版盲排**代替「与得奖作混排」；
- 判据改为「定稿版排第 1，且两位评委独立指到同一处 → 改 → 复看」；
- 全程记录原文，不修饰结论。

## 第 1 轮（2026-11-19 22:15）

三个不同的「借塔」构图，随机命名为 `proof/gate-d/blind/{B,D,F}.png`：

| 版本 | 参数 | 说明 |
| --- | --- | --- |
| D | 柱 470 / 1210，雾 400 | 定稿版 |
| F | 柱 420 / 1270，雾 380 | 更开阔 |
| B | 柱 640 / 1230，雾 410 | 更紧凑 |

两位评委（同一模型家族，代理人身份，未参与制作）：

- **评委甲**：F > B > D。对定稿版的批评：「塔几乎贴住右柱，左侧留空太多，画面重心歪了。」
- **评委乙**：D > B > F。对定稿版的批评：「塔的右缘到右柱只剩约 144px，左边却空出约 590px……整个窗口的重心全压在右侧。」
  同时抓到两处真实缺陷：F 的左柱压住说明文字；B 的右侧柱脚被右下判据卡切掉。

**两位独立指到同一处：塔贴右柱、左侧空太多。** 按「两轮同处」规则，这是真问题，必须改。

## 改法

1. **加一条判据**：两侧留白要匀（`|左留白 − 右留白| ≤ 140`）。这一条不是补丁，是把「构图平衡」变成可判定的规则——
   玩家不再能把塔挤到一根柱子上。
2. **放宽柱的可动范围**（左 ≤ 820、右 ≤ 1500），否则宽而匀的构图够不着。
3. **修 HUD 压字**：左下文案加纸底渐变、右下判据卡改为不透明纸面 + 投影，柱子在卡片后面也读得出是「卡片在前面」。

## 第 2 轮（2026-11-19 22:50，改后复看）

三版重新命名为 `proof/gate-d/blind2/{K,M,R}.png`，另一位没看过第 1 轮的评委：

- **K（新定稿）> M > R**。原话：「塔正好落在两柱正中（左留白 325px、右 321px），廊框最稳，视线不会被扯走。」
- 残留问题（照原文记）：
  1. 右侧廊柱被右下「落印」面板切掉柱脚——卡片不透明后读作「面板在前」，但柱子确实断在卡片边缘。
  2. 灰小字（旁白）横穿亮色栏杆与水面带，中段偏淡。
- 第 1 轮两位指出的「重心偏右」已消失。

## 结论

**条件性通过**：定稿版在两轮里都拿到一位评委的第 1（第 1 轮乙、第 2 轮丙），第 2 轮明确确认平衡问题已解决；
但因为首届无往届得奖作可混排、且评委同属一个模型家族，按规则**不计为过线**，如实记为条件性，交用户裁决。
