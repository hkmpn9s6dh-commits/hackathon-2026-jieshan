## 3. 两说并存的地方（不装作只有一个答案）

- **初建年代**：无锡市档案史志馆写「明正德中（1506—1520）」；太湖风景区一文写「明嘉靖六年（1527）」。
  正文取「明·正德年间（约 1527）」，把两说都收进这个区间，不假装精确到年。
- **临幸次数**：一处写「康熙、乾隆各六次南巡，均必到此园」；另一处写「康熙七次游寄畅，乾隆十一次巡秦园」。
  数字不一致，正文不写具体次数，只写「皇帝来了」。
- **叠山者名字**：张涟之侄，文献里有「张轼」「张鉽」「张钺」三种写法（同一人）。正文不写人名。
- **八音涧长度**：36 米（《筑山理水》）。只写在 `03-SOURCES.md`，不进页面，避免为一个数字背书。

## 4. 工具选择的说明（赛道 B 的 LayaIdea）

赛道 B 提供 LayaIdea AI 游戏工作台。本作没有用它，理由：本作的核心是**可判定的构图几何**——
每一关的判定要能用同一份坐标算出「塔是否在两柱之间」「山脊是否整条露出」。
自然语言生成式工作台给不了这种控制，所以改用 TypeScript + Canvas 2D 自己画。

这不是规避赛事工具，是选择：工具是「提供」，不是「必须」（官方页原文只写「免费技术工具」）。
如果赛事方要求必须使用，本作可以照 LayaIdea 重做一版——机制与判据是独立的，换渲染层不影响玩法。
