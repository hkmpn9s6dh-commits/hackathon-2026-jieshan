# 07 · UI

## 1. 风格预设

**「绢本淡墨 + 朱印」**：纸白为底，墨分五色，全画面只有一处彩色——朱红。

- 纸 `#efe7d6`｜墨 `#1d2321`｜淡墨 `#4a524d`｜灰墨 `#8b9187`｜朱 `#a4382a`｜金 `#a3833f`
- 字体：Noto Serif SC（SIL OFL 1.1），随包子集；标题字距 0.3em，正文 0.05em
- 不用渐变按钮、不用投影卡片、不用圆角图标；所有按钮是发丝线框
- 画面里唯一的「现代物」是第 5 关的高楼——它是灰的，冷，且明显不属于这张纸

## 2. 尺子（各学一点）

| 参照 | 学哪一点 |
| --- | --- |
| 《绘真·妙笔千山》（网易 × 故宫） | 画面本身就是舞台：不给 HUD 加框，让 UI 退到纸的边缘 |
| 故宫《千里江山图》数字长卷 | 观看节奏靠「停」不靠「动」；一屏一景，别让人一直滑 |
| 腾讯功能游戏《折扇》《榫卯》 | 一项技艺压成一个动作：折扇是「折」，榫卯是「合」，本作是「借」 |
| 《Monument Valley》 | 几何即玩法：判定要一眼可读，不能让玩家猜规则 |
| 《Florence》 | 单关 2–4 分钟；机制随情绪变，不靠加难度 |
| 《Gris》 | 色板随章节收敛：第 4 关去饱和，第 5 关只留朱与墨 |

> 这六件都不是本届同赛道作品（首届，无往届可参照），属「同类参照」。闸 D 因此用同题三版盲排，
> 记录见 `docs/06-GATE-D.md`。

## 3. 一个记忆点

**塔落在两根廊柱之间，雾埋住塔脚。**

一句话能复述、一张图能认出来。所有的版面决定都让位于这一帧：柱子要立得住，塔要正，雾要软。

## 4. 主屏规格

| 项 | 值 |
| --- | --- |
| 逻辑画布 | 1600 × 900（16:9），按窗口等比缩放，最大 2× DPR |
| 安全边 | 左右各 46 px、上下各 30 px 内不放可动对象 |
| HUD 位置 | 上左：年代＋关名；上右：关序＋音／说明／出处；下左：任务句＋旁白；下右：判据卡 |
| 判据卡 | 宽 310–420 px，半透纸底 + 1 px 线框；每条一行，红点＝已满足 |
| 落印按钮 | 只在全过时出现；朱底白字，字距 0.34em；2.6 s 呼吸 |
| 触控目标 | 可动对象的命中区 ≥ 88 × 88 px（缩放前） |
| 首屏 | 只有标题、一行题眼、一个「入园」，以及一句玩法说明 |

## 5. 已知弱点与改法（留给下一场）

1. **第 2 关的柱与檐仍是平面图形**，没有透视与厚度；近景建筑的可信度靠雾与水遮。
   下一场若要正经做建筑内景，得先做一套有灭点的柱枋组件。
2. **水面反射是「切片抖动」不是真反射**，近看能看出横向条纹；远看成立。
3. **第 4 关的断墙**用程序化砖层画，砖缝规律性偏强；真做旧需要一张材质图。
4. **右下判据卡会切掉右侧廊柱的柱脚**（闸 D 第 2 轮评委指出）：卡片已改为不透明纸面，
   读作「面板在前」，但柱子确实断在卡片边缘。下一场把判据改成底部横排即可。
5. **旁白小字穿过亮色水带**时对比不足（已加纸底渐变，仍偏淡）。下一场给旁白一个固定的纸底块。
6. **手机竖屏只能横着看**：画布按 16:9 装进 390 宽，高度只有 219，字看得见但图小。
   下一场若要主打手机，得改成竖构图或做两套版式。
